# Free QR Code Generator

Live site: **https://sabithpkcmnr.github.io/qr-code-generator/**

Create a custom QR code in the browser and download it as PNG, JPG, WebP, or SVG. No signup and no watermark.

## Run locally

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

Then open http://127.0.0.1:5173/
